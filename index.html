E-Commerce Customer Satisfaction Analysis

Built an end-to-end e-commerce analysis in Power BI and Python, using Power Query, DAX and statistical analysis to identify the key drivers of customer satisfaction.

View case study +
Problem

Which operational factors most meaningfully predict customer review score and is delivery timing actually the lever it appears to be once price and freight cost are controlled for?

Approach

Cleaned and modeled the data in Power Query, built DAX measures for the key metrics, then ran statistical analysis in Python to test candidate drivers rather than assume them.

Result

Surfaced the factors with real statistical influence on satisfaction and packaged them into a Power BI dashboard stakeholders could act on.

SQL Tableau

California County Fiscal Trend Reliability Analysis

SQL-driven analysis of 21 years of county financial data, distinguishing genuine fiscal trends from statistical noise using window functions and a custom reliability ratio.

View case study +
Problem

Year-to-year swings in county finances can look like meaningful trends when they are really just noise — a risk for anyone making policy calls off them.

Approach

Built a SQL pipeline over 21 years of data across all 57 counties using window functions, and designed a custom reliability ratio to separate genuine trends from noise.

Result

A Tableau dashboard that flags which county fiscal trends are statistically reliable versus which are noise.

Tableau Python

California County Spending Efficiency Dashboard

Tableau dashboard analyzing per-capita government spending across all 57 California counties, with population-tier normalization to correct for small-county skew.

View case study +
Problem

Raw per-capita spending comparisons unfairly penalize small counties, making efficiency comparisons across counties misleading.

Approach

Used Python to normalize spending by population tier, then built an interactive Tableau dashboard for county-to-county comparison.

Result

A fairer, tier-adjusted view of government spending efficiency across all 57 counties.
